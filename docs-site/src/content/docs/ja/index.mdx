**理解できるほど小さく、信頼できるほど強い。** Sinter は単一の Rust
バイナリで OS の構成を記述・適用します。管理対象ホストにエージェントも
Ruby や Python のランタイムも不要です。

```yaml
version: 1

resources:
  - id: tree
    type: package
    with:
      name: tree
      state: present
```

```sh
sinter validate recipe.yaml
sinter plan --host server.example.com recipe.yaml
sinter apply --host server.example.com --sudo recipe.yaml
```

## 主な特徴

<CardGrid>
  <Card title="エージェントレス" icon="rocket">
    管理対象ホストに必要なのは OpenSSH、`/bin/sh`、systemd、そして
    `sudo -n` のみ。ターゲットに Sinter のランタイムはインストールされません。
  </Card>
  <Card title="plan は観測のみ" icon="magnifier">
    `sinter plan` はファイルの書き込み、パーミッションの変更、
    パッケージのインストール、command リソースの実行を一切行いません。
  </Card>
  <Card title="設計された冪等性" icon="approve-check">
    ターゲットがすでに目的の状態と一致している場合、同じレシピを
    2 回適用しても変更はゼロです。
  </Card>
  <Card title="フェイルクローズ" icon="warning">
    未知の SSH ホスト鍵、安全でないパス、予期しないシンボリックリンク、
    検証の失敗は、推測せずに実行を停止します。
  </Card>
</CardGrid>

## 対応プラットフォーム

| プラットフォーム | アーキテクチャ | パッケージバックエンド |
|------------------|----------------|------------------------|
| Ubuntu 24.04 LTS | amd64 | apt |
| Ubuntu 26.04 LTS | amd64 | apt |
| Rocky Linux 9 | x86_64 | dnf |
| Rocky Linux 10 | x86_64 | dnf |

受入基準環境: Rocky Linux 9.8 x86_64（DNF 4.14.0）、Rocky Linux 10.2
x86_64（DNF 4.20.0）、Ubuntu 24.04.4 amd64、Ubuntu 26.04.1 LTS amd64。
完全なマトリクスと要件は[対応プラットフォーム](/sinter/ja/compatibility/platforms/)を参照してください。
