---

このドキュメントサイトは、[WebMCP](https://webmcp.org/)（Web ページが
ホストするツールを AI エージェントや対応ブラウザから呼び出せるブラウザ API）
を通じて、少数の**読み取り専用ドキュメント検索ツール**をオプションで公開
しています。これらのツールは**ドキュメント参照専用**です。Sinter を実行
したり、ターゲットに接続したり、何かを変更したりすることは一切ありません。

## 利用可能条件

ツールが登録されるのは、閲覧環境が WebMCP（`document.modelContext` /
`navigator.modelContext` API）に対応している場合だけです。非対応の
ブラウザやクライアントでは何も登録されず、サイトは通常のドキュメント
サイトとして動作します。対応が必要な操作はありません。エージェント対応
クライアントは、サイトを閲覧すると自動的にツールを検出します。

## ツール一覧

| ツール | 目的 |
|--------|------|
| `sinter_search_docs` | ドキュメントインデックスのフリーテキスト検索。ページのタイトル、URL、要約を返します。 |
| `sinter_list_resources` | 現在のリリースのレシピリソースタイプを 1 行の要約とドキュメント URL 付きで一覧表示します。 |
| `sinter_get_resource` | 1 つのリソースタイプ（`file`、`directory`、`link`、`template`、`command`、`package`、`service`）の完全なパラメータリファレンス。 |
| `sinter_get_compatibility` | 対応プラットフォームマトリクス、受入基準環境、管理対象の要件。 |
| `sinter_get_installation` | プラットフォーム（`linux-x86_64`、`source`。旧Ubuntu/Rocky識別子は別名として維持）ごとのインストール手順。 |

同じ機械可読データは `/webmcp/en.json` と
`/webmcp/ja.json` でも JSON として直接提供されています。

## ロケール

すべてのツールは省略可能な `locale` 入力（`en` または `ja`）を受け付けます。
省略した場合は、現在閲覧中のページからロケールを検出します
（`/ja/...` → `ja`、それ以外は `en`）。不正なロケールは、サポート
されるロケール一覧とともにクリーンに失敗し、ローカライズされたデータが
利用できない場合は、エラーではなく英語のデータにフォールバックします。

## スコープ

これは**ドキュメントサイトの機能**です。Sinter 本体は現在、実行用や
ランタイムの MCP ツールを一切公開していません。将来それが変わる場合は、
別の明示的にドキュメント化された機能になります。
