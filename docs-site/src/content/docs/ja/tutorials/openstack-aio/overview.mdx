このチュートリアルでは、Sinter の公式レシピ
[`examples/openstack/`](https://github.com/hagix9/sinter/tree/main/examples/openstack) を使い、
Rocky Linux 10.2 の 1 台のサーバーに **OpenStack 2026.1（Gazpacho）の All-in-One（AIO）** を構築します。
コマンドは、上から順にコピーして実行できる形で載せています。

<Aside type="caution" title="検証・デモ用の構成です">
このレシピは Sinter を実際のワークロードで評価するためのもので、本番運用向けの安全強化はしていません。
SELinux は permissive、RPM は無署名で `gpgcheck=0` です。
OpenStack の API と Horizon をインターネットに公開しないでください。
詳しくは[セキュリティ上の制限](#セキュリティ上の制限)を読んでから始めてください。
</Aside>

## 完成イメージ

最後まで進めると、次の状態になります。

- **Keystone で認証できる**: `openstack token issue` が成功する。
- **Nova、Neutron（OVN）、Glance、Placement、Keystone の API が動く**: エンドポイントが 15 件（各サービスの admin、internal、public）。
- **KVM の上で仮想マシンが動く**: CirrOS 0.6.3 が `ACTIVE` になり、libvirt の domain type が `kvm`。
- **仮想マシンに届く**: ping が 0% loss、SSH でログインできる（ホスト鍵を検査）。
- **Horizon で管理できる**: ログインページが表示され、admin でログインできる。
- **Sinter で管理し続けられる**: 2 回目の `apply` が 0 changed、`audit` が `no_drift`。再起動後も同じ。

確認のしかたは手順 5 で説明します。

いずれも 2026-10-17 に実機（GCE、Rocky Linux 10.2）で確認した結果です。
Horizon の画面のスクリーンショットは保存していないため、このチュートリアルには載せていません。

## 構成図

<OpenStackTopology locale="ja" />

- **操作端末（あなたの PC）**: ビルダーと AIO サーバーに SSH でログインして作業します。Sinter を入れる必要はありません。
- **RPM ビルダー兼 Sinter 実行ホスト**: 使い捨ての Rocky Linux 10.2 です。
  - `sinter apply builder.yaml` を自分自身に（ローカルで、root として）実行し、OpenStack の RPM をビルドします。
  - ① `tools/stage-rpm-repo.sh` で、RPM を SSH 経由で AIO サーバーの `/opt/hagistack-repo` へ転送します。
  - ② `sinter plan / apply / audit all-in-one.yaml` を、SSH と `sudo` で AIO サーバーに実行します。生成した秘密情報（`secrets/`）もここに置きます。
- **OpenStack AIO サーバー**: OpenStack のすべてのサービスが動きます。
  転送された RPM は `127.0.0.1:8088` のローカルリポジトリとして配信され、そこからインストールされます。
  CirrOS の仮想マシンは KVM の上でテナントネットワークにつながります。
- **インターネット**: ビルダーはソースと依存パッケージを、AIO サーバーは Rocky、EPEL、NFV SIG、RDO のパッケージと CirrOS のイメージを取得します。

この配置（ビルダーが Sinter の実行ホストを兼ねる）は、実機受入で使った構成と同じです。

## 必要な環境

### サーバー

**AIO サーバー**

- OS: **Rocky Linux 10.2 x86_64（必須）**
- CPU / メモリ / ディスク: 4 vCPU / 16 GB / 空き約 50 GB 以上（最低限の目安）
- 仮想化: **`/dev/kvm` が使えること（必須）**。クラウドでは nested virtualization を有効にする
- ネットワーク: インターネットへの外向き通信、ビルダーからの SSH
- その他: `dnf-plugins-core`、`attr`（`getfattr`）、パスワードなしの `sudo`

**RPM ビルダー**

- OS: **Rocky Linux 10.2 x86_64（必須）**
- CPU / メモリ / ディスク: AIO サーバーと同程度
- 仮想化: 不要
- ネットワーク: インターネットへの外向き通信
- その他: パスワードなしの `sudo`、`openssl`（秘密の生成）。**使い捨てにする**（OpenStack のノードと兼用しない）

- 受入では、両方とも GCE の `n2-standard-4`（4 vCPU / 16 GB）と 60 GB の balanced ディスクを使いました。AIO サーバーは nested virtualization を有効にしました。
- メモリとディスクの量は、レシピの事前チェック（preflight）では検査しません。足りないと途中で失敗します。
- このチュートリアルでは、**ビルダーと AIO サーバーに同じユーザー名でログインできる**ことを前提にします（受入と同じ）。

### 事前チェックで確認される項目（必須）

AIO サーバーへの `apply` は、何かを変更する前に次を確認し、1 つでも合わなければ止まります。

- OS が Rocky Linux 10.x の x86_64 であること
- `hostname -s` が、設定ファイルの `os_hostname` と同じであること
- 設定ファイルの `mgmt_ip` が、AIO サーバーのいずれかのインターフェースに付いていること
- `/dev/kvm` が読めること（`virt_type: kvm` のとき）
- `dnf-plugins-core` が入っていること

### ネットワーク

- **操作端末 → ビルダー、AIO サーバー（SSH）**: 作業とログイン。
- **ビルダー → AIO サーバー（SSH、TCP 22、内部ネットワーク）**: RPM の転送と Sinter の実行。
- **ビルダー → インターネット（HTTPS）**: GitHub（hagistack と Sinter）、Rust のツールチェーンと crate、OpenStack のソース、RDO、EPEL、Rocky のリポジトリ。
- **AIO サーバー → インターネット（HTTPS）**: Rocky、EPEL、CentOS Stream NFV SIG、RDO のリポジトリ、CirrOS のイメージ。

OpenStack の API と Horizon への接続は、インターネットから受け付けないでください。
受入でも、クラウド側のファイアウォールは SSH、ICMP、VPC 内部の通信だけを許可し、確認はサーバーの内側から行いました。

### Sinter

レシピが使う機能の上では Sinter v1.5.0 以降が必要です。
このチュートリアルでは、受入と同じソースからビルドする方法を主に説明します（手順 2）。

## セキュリティ上の制限

このレシピは移植元の hagistack の選択をそのまま引き継いでおり、本番向けの安全な既定値ではありません。

- **SELinux を permissive にします**（実行時と起動時）。Enforcing では検証していません。
- **OpenStack の RPM は無署名**で、自前ビルド、NFV SIG、RDO のリポジトリは `gpgcheck=0` です。
  `rpm -K --nosignature` はダイジェストの検査であり、**署名の検証ではありません**。
  ビルダーと AIO サーバーの間の整合性は SHA-256 で確認します（手順 3）。
- **firewalld はイメージの既定のまま**にします。受入に使ったクラウドのイメージでは既定のゾーンが `trusted` で、
  ホストのファイアウォールはすべてのポートを受け付けていました。
- **すべてのサービスが管理ネットワークで待ち受けます**。同じ VPC のほかのホストなど、管理アドレスに届くものからは
  MariaDB、RabbitMQ、API、Horizon に到達できます。AIO サーバーは隔離されたネットワークに置いてください。
- ローカルの RPM リポジトリ（127.0.0.1）など、一部のローカルの待ち受けには認証がありません。
- **秘密情報**はビルダーの `secrets/`（Git の管理外）に生成し、AIO サーバーでは root だけが読めるファイルに書きます。
  `secrets.example/` は CI 用の合成値で、**絶対に使わないでください**。
- 本番運用に必要な TLS、ファイアウォール、アクセス制御、冗長化は含みません。

## RPM の扱い

OpenStack 2026.1 の EL10 向け RPM はどこからも配布されておらず、**このプロジェクトも RPM を配布しません**。
手順 3 で、使い捨てのビルダーで公開ソースから自分でビルドします（README の「方式 B」）。
ビルドした RPM には、それぞれのライセンスで同梱される第三者のコードが含まれます。
ライセンスを確認しないまま再配布しないでください。
取得元とライセンスの詳細は、レシピの [README](https://github.com/hagix9/sinter/blob/main/examples/openstack/README.md#sources-and-licenses) を参照してください。
