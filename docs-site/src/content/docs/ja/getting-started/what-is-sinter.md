---
title: Sinter とは
description: プロダクト概要 — Rust 製のエージェントレスな Linux 構成管理。
---

Sinter は Itamae にインスパイアされた、軽量でエージェントレスな構成管理
ツールです。単一の Rust バイナリで OS の構成を記述・適用します。
管理対象ホストには Sinter エージェントも Ruby や Python のランタイムも
不要で、SSH サーバ、`/bin/sh`、systemd、そして権限昇格が必要な場合は
パスワードなしの `sudo -n` だけが必要です。

## 設計目標

- **理解できるほど小さい。** 意図的に絞られたスコープ: インベントリ、
  ロール、プラグイン、オーケストレーション、組み込みスクリプトは
  ありません。
- **信頼できるほど強い。** 観測のみの plan、すべての変更の前の再観測、
  厳格な SSH ホスト鍵チェック、フェイルクローズなパース、誠実な
  結果報告。
- **冪等。** すでに一致しているレシピを再適用しても変更はゼロです。

## 実行の流れ

```sh
sinter validate recipe.yaml                          # スキーマチェック。ターゲットには接続しない
sinter plan --host web01.example.com recipe.yaml     # 観測のみ
sinter apply --host web01.example.com --sudo recipe.yaml
```

`plan` は非公式なプレビューを生成します。`apply` は変更の要否を判断する
直前にすべてのステートフルなリソースを再観測します。過去の plan が
現在の状態として再利用されることはありません。

## 対応する管理対象

| プラットフォーム | アーキテクチャ | パッケージバックエンド |
|------------------|----------------|------------------------|
| Ubuntu 24.04 LTS | amd64 | apt |
| Rocky Linux 9 | x86_64 | dnf |

要件と受入基準環境は[対応プラットフォーム](/sinter/ja/compatibility/platforms/)を参照してください。

## Sinter でないもの

Sinter は汎用のオーケストレーションシステムの代替を目指していません。
インベントリもエージェントデーモンもテンプレート用プログラミング言語も
クラスタ全体の協調もありません。個々の Linux ホストの構成を記述・適用
するための小さなツールです。
